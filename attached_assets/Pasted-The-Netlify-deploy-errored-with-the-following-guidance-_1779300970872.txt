- Error type and cause: npm exited with code 127 because the shell tried to run the husky binary but it was not installed ("sh: 1: husky: not found") ([line 75](#L75)). This commonly happens when:
  - Husky is referenced by a package.json script (e.g. "prepare": "husky install") but the husky package is not installed, or
  - Netlify installed only production dependencies (devDependencies were omitted) and husky is only listed as a devDependency, so the prepare script runs but the binary isn’t present.

Solution — quick checklist and fixes
1) Verify whether husky is present in the package.json that Netlify uses for the build
- Confirm which package.json Netlify is building (Netlify's log shows "Swapping in standalone package.json" [line 68](#L68)). Open that package.json in your repo (or the project subfolder Netlify targets) and check for:
  - any "prepare" or postinstall script that runs "husky" and
  - whether "husky" appears under "dependencies" or only under "devDependencies".
- Example check locally:
  - cat package.json | grep -n '"husky"\|"prepare"' (run in the project directory Netlify builds).

2) If your build needs husky to run, add it to dependencies (so it’s installed in production) and commit
- Edit package.json and move/add husky to "dependencies" (not just devDependencies). Example snippet:
```json
{
  "dependencies": {
    "husky": "^8.0.0"
  }
}
```
- Then run npm install, commit, and redeploy.

3) If husky is NOT required during CI build (recommended for most CI/CD flows), skip husky install during Netlify builds
- Add an environment variable so husky's install step is skipped in CI. Two easy options:
  - In netlify.toml:
```toml
[build.environment]
  HUSKY_SKIP_INSTALL = "1"
```
  - Or set the same env var in Netlify UI (Site settings → Build & deploy → Environment → Add variable HUSKY_SKIP_INSTALL = 1).
- Or export the var at the top of your netlify-build.sh:
```bash
export HUSKY_SKIP_INSTALL=1
# then your existing build steps
```

4) (Alternative) Instruct Netlify to install devDependencies (not usually recommended)
- If you must install devDependencies, set NPM_FLAGS so npm installs dev deps (example):
  - In netlify.toml:
```toml
[build.environment]
  NPM_FLAGS = "--include=dev"
```
- Note: prefer skipping husky in CI instead of installing all devDependencies.

Why this fixes it
- The error is the husky binary missing when npm runs a script that calls it. Either ensure the binary exists by installing husky as a dependency, or prevent the script from running in CI by setting HUSKY_SKIP_INSTALL.
